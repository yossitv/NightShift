## Frontend

This directory contains the Night Shift frontend bootstrapped with the
Next.js App Router.

## Stack

- Next.js 16 App Router
- React 19
- TypeScript
- ESLint
- Tailwind CSS v4

## Getting Started

Install dependencies and start the development server:

```bash
cd frontend
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in the browser.

The main App Router entry points are:

- `app/layout.tsx`
- `app/page.tsx`

## Verification

```bash
npm run lint
npm run build
```
